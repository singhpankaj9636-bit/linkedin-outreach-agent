# 🤝 LinkedIn Outreach Agent

> AI-powered B2B outreach messages for SaaS founders — generated in seconds.

## 🔗 Live Demo
👉 [Try it here](https://linkedin-outreach-agent-cukam2yvxypctg9ajpz9w8.streamlit.app/)

## 🚀 What it does
- Generates personalized **LinkedIn connection requests**
- Writes **follow-up DMs** with clear CTAs
- Tailored to prospect's company, role, and pain point
- 4 tone options: Professional, Casual, Bold, Warm

## 🛠️ Built With
- Python
- Streamlit
- Groq API
- LLaMA 3.3-70b

## 💡 Use Case
SaaS founders and B2B sales teams who want to scale outbound outreach without spending hours writing manual messages.
